# LocalStore-Ecommerce
A local store e-commerce platform that allows customers to browse products, view product details and prices, add items to a shopping cart, and purchase products online.

🚀 Features

. Browse products

. View product details

. Add products to the shopping cart

. Shopping cart functionality

. Checkout page

. Order success page

. Order tracking

. Contact page

. Responsive user interface

🛠️ Technologies Used

HTML5

CSS3

JavaScript
